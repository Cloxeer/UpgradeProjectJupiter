# SpyderWeb Dev — Behavior Sweep

## Scroll Behaviors
- Header becomes sticky after ~300px scroll on desktop (>=992px)
- Back-to-top button appears after 300px scroll
- No Lenis/smooth scroll library detected — native scroll

## Click Behaviors
- Service superboxes expand on click (mobile) / hover (desktop) revealing secondary content
- Hamburger opens full mobile nav with mega-menu dropdowns
- All CTA buttons link to /contact/#schedule-a-call or external URLs

## Hover Behaviors
- `.btn-hover-effect` buttons: subtle lift/shadow on hover
- Service cards: primary panel reveals secondary on hover (desktop)
- Footer links: color shift to primary orange

## Responsive Breakpoints
- Mobile menu below ~992px
- Grid sections stack to single column below ~1024px (grid--l-1)
- Service cards stack vertically on mobile with "Tap to learn more" visible
