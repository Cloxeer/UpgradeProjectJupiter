# SpyderWeb Dev Homepage Topology

Target: https://spyderwebdev.com/

## Section Order (top to bottom)

1. **Header** — sticky overlay, white bg, logo left, nav center (desktop), hamburger right (mobile)
2. **Hero** — starry night bg with dark overlay, headline + CTA + ratings, portfolio mockup right
3. **Value Props Bar** — orange/navy gradient strip with 3 value headlines
4. **Services Accordion** — "What does your business need help with?" with 6 expandable cards
5. **Velocity Sites CTA** — orange section for home service businesses
6. **About / Differentiators** — two-column: copy left, 4 value cards right
7. **Portfolio** — alternating project showcases (4 projects)
8. **Recent Posts** — 3 blog cards + pagination
9. **Reviews / Badges** — gradient section with Google review graphic + certification badges
10. **Contact CTA** — "Ready to have a chat?" with two buttons
11. **Footer** — logo, contact, social, link columns, copyright

## Interaction Models

- Header: sticky on scroll (scroll > 300px), click-driven mobile menu
- Services cards: click/hover expand on desktop (superbox), tap on mobile
- All CTAs: click navigation (external links preserved)
- Back to top: scroll-triggered visibility
